## 줄바꿈 규칙 (Screens.kt)
- 한글은 어절(띄어쓰기) 단위로만 줄을 바꾸고 줄 길이를 고르게 맞춘다(Text 래퍼).
- 주요 버튼은 스크롤 영역 밖 하단에 고정한다(Page(footer=...)). 글이 길어져도 잘리지 않는다.
- 버튼·칩 라벨은 한 줄, 하단 안내 캡션은 한 줄(말줄임)로 고정해 레이아웃이 밀리지 않는다.

## 모션 규칙
- 정차 중 화면: 화면 전환, 카드 순차 등장, 터치 눌림, 상태 색 전환, 진행률, 경고 고리, 히어로 장식 이동.
- 주행 중(차단 화면): 반복 모션 전부 정지.
- 근거: Pleos UI 가이드는 "운전 중" 시선 유도를 금지한다(docs/03 §8.1).
