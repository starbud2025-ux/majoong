## 기획서 뼈대
1. **제안 요약**: 한 줄 + 핵심 화면 1장
2. **문제**: 주차·하차·출발 시점의 실수와 영향(근거 자료는 출처 확인 후 인용)
3. **솔루션**: F1~F4와 사용 흐름(수명주기 다이어그램)
4. **사용 시나리오**: 데모 3분 시나리오를 화면 캡처와 함께
5. **Pleos SDK 활용**: 기능별 API 표(`docs/03`의 확정본)
6. **안전·UX 설계**: 정차 전용, 동의 후 제어, 결과 확인, 오류 처리
7. **개인정보**: 기기 내 처리, 서버 전송 없음
8. **차별점**: 수명주기 묶음, 정차 전용 안전 설계(유사작 비교는 사실 확인 후 최소한으로)
9. **한계와 향후 확장**
   - 구역 데이터: 공공 데이터 연동, 갱신
   - **플랫폼에 요청하는 API**: 주변 차량·카메라 이벤트 클립(문콕·뺑소니 증거), 근접 감지, 뒷좌석 전용 오디오 존, 외기 온도·성에 감지 신호
   - 법적·개인정보 검토가 필요한 항목은 "검토 필요"로 명시하고 효과를 단정하지 않는다
10. **구현 현황**: 완료·부분·미구현을 표로 정직하게 표기

## 아이디어 특별상 관점 메모
구현 범위 밖의 아이디어(문콕·뺑소니 영상 공유, 자동 경적, 긴급 알림 네트워크)는 9번 "향후 요청 API"에 **필요한 API·동의 구조·프라이버시 설계**와 함께 서술한다. 구현한 것처럼 쓰지 않는다.
